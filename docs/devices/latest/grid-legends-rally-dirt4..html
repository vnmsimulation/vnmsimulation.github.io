Grid Legends will not recognise the VNM Direct Drive Firmware out of the box. Support needs to be added manually, as follows:

Find the game installation directory, go to GridLegends\input\devices and edit the file: device_defines.xml (change GridLegends to the exact Game you want)

Add the following line to the end of the list

<device id="{A3D50483-0000-0000-0000-504944564944}" name="vnm_direct_drive" priority="100" type="wheel" official="false"/>
