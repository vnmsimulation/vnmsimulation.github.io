Connection

The connection port is located at the lower-rear of the shifter.

  • Plug in USB cable to connect to PC.

  • Use the switch to select mode:

    • H shifter mode

    • Sequence mode

  • Plug in truck knob (if applicable).

  • Use the switch to select DFU Mode (update firmware) or RUN Mode (play in game).

Adjust Spring / Force

H-Pattern Force

Turn the adjustment screw clockwise to increase force.

If there is a locking screw present, loosen it first before adjusting the force.

Sequence Grid Force

Turn the adjustment screw clockwise to increase force.

Vibration Damping

You can install the M5×4 screw if your shifter has excessive vibration. (Screw is included in the accessory box.)

Adjust Y Axis

Adjust the Y-axis position using the corresponding adjustment point on the shifter body.

Exchange Face & Knob (H)

The front face plate and H-pattern knob can be swapped as needed. Refer to the hardware diagram on the packaging for screw positions.

Mode Change

Use the mode switch to select between H-pattern and Sequential modes.

Mode Description

H-Pattern

6R Manual gearbox (gear positions: 1, 2, 3, 4, 5, 6, R)

Sequential

Sequential gearbox (push/pull)

H-Pattern Gear Layout

  1 | 3 | 5
  --|---|--
  2 | 4 | 6
           R

Hold the knob down when engaging Reverse ® gear.

Mounting Drawing & Table Clamp

Refer to the mounting drawing for correct installation dimensions and table clamp attachment points.

  • Secure the clamp to a desk edge (max thickness: see drawing).

  • Align the shifter base plate with the clamp mounting holes.

  • Tighten all screws with the supplied hexagon key.
